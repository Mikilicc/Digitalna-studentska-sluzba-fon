# Digitalna studentska sluzba fon (fonis mini-hackaton)

## ❓ O projektu
Projekat je nastao tokom mini-hakatona u okviru trećeg kruga selekcije za članstvo u FONIS-u. Razvijen je za svega 3 sata, koristeći JavaScript, HTML i Tailwind CSS. U pitanju je demo verzija projekta, bez implementiranog backenda, namenjena za prikaz osnovne ideje i funkcionalnosti.
